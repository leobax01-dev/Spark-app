# SPARK_OS Execution Rules for Claude Code

1. Always check `SPARK_OS/02-Tasks` for pending work files before starting.
2. Read `SPARK_OS/04-Memory/architecture.md` to understand tech stack boundaries before writing code.
3. Keep code modular, clean, and tested. Run local checks/builds before confirming task completion.
4. After completing a task, move the task file or update its status to [DONE] and write a quick summary log in `SPARK_OS/05-Daily-Briefings/`.
5. Never log production secrets or `.env` keys directly into markdown files.
